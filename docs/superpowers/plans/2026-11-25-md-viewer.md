# md ビューア改良 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 単一ファイルの Markdown プレビューアを、ライブリロード・ディレクトリ閲覧・目次・ダークモード付きのビューアに作り替える。

**Architecture:** `main.py`（標準ライブラリのみ）がルートディレクトリ以下のファイル・JSON API・SSE を `127.0.0.1` で配信し、ビルド済みの Preact SPA（`frontend/dist/`）を `/_md/` 配下で返す。Markdown の変換はすべてブラウザ側（markdown-it）で行う。サーバーはポーリングで mtime を監視し、変更を SSE で通知する。

**Tech Stack:** Python 3.14 標準ライブラリ / Preact + TypeScript + Vite / markdown-it, markdown-it-footnote, markdown-it-anchor, markdown-it-github-alerts, @vscode/markdown-it-katex, katex, highlight.js, mermaid, github-markdown-css, github-slugger / vitest + @testing-library/preact + happy-dom / @playwright/test

**Spec:** `docs/superpowers/specs/2026-11-25-md-viewer-design.md`

## Global Constraints

- `main.py` は Python 標準ライブラリのみ。`~/.local/bin/md` → `main.py` のシンボリックリンクで動くこと（自分の場所は `Path(__file__).resolve()` で特定）。
- `main.py` は `if __name__ == "__main__": main()` でガードし、テストから `import main` できること。
- 待ち受けは `127.0.0.1` のみ。
- ポート: 未指定なら 8000 から順に空きを探す（8000〜8099）。`-p/--port` 指定時はそのポートのみで、使用中なら終了コード 1 でエラー表示。
- フロントエンドの依存は npm で同梱し、実行時に CDN を使わない。パッケージマネージャは npm。
- `frontend/dist/` と `node_modules/` はコミットしない。
- ツリー対象: 拡張子 `.md` / `.markdown`（大文字小文字無視）。除外: `.` で始まる名前、`node_modules`、`__pycache__`、`venv`。`.gitignore` は解釈しない。
- E2E はシステム Chrome（`channel: 'chrome'`）のみ。
- UI の文言は日本語。

## URL 設計（全タスク共通）

| パス | 内容 |
|---|---|
| `/_md/` 以下（`/_md/api/` を除く） | `frontend/dist/` の静的ファイル（Vite `base: '/_md/'`） |
| `GET /_md/api/tree` | `TreeResponse` JSON |
| `GET /_md/api/raw?path=<相対パス>` | Markdown の生バイト（`text/plain; charset=utf-8`）。ルート外 403、無ければ 404 |
| `GET /_md/api/events` | SSE |
| その他のパスで `Accept` に `text/html` を含み、対象が `.md`/`.markdown`/ディレクトリ/ルート | `dist/index.html`（SPA） |
| その他 | ルート以下の静的ファイル。ルート外 403、無ければ 404 |

```ts
// frontend/src/types.ts（Python 側も同じ形の JSON を返す）
type TreeNode =
  | { type: "file"; name: string; path: string }              // path はルートからの "/" 区切り相対パス
  | { type: "dir"; name: string; path: string; children: TreeNode[] };
type TreeResponse = { rootName: string; initial: string | null; tree: TreeNode[] };
// SSE イベント
//   event: change  data: {"path": "docs/a.md"}   … .md ファイルの mtime 変化・再出現
//   event: tree    data: TreeResponse            … .md の集合が変化
//   15 秒ごとに ": ping" コメント行
```

## Review Focus

1. **日本語・空白・`#`・`%` を含むファイル名**: ツリー表示、`/_md/api/raw` の取得、URL 遷移、画像の表示がすべて動く。→ Task 2 と Task 6 にテストを追加。
2. **エディタの「一時ファイルに書いて rename」保存（vim など）**: 一瞬ファイルが消えても削除エラーのまま残らず、更新として反映される。→ Task 2（watcher）と Task 6（E2E）。
3. **ルート外への脱出**: `..`、`%2e%2e`、ルート外を指すシンボリックリンクはすべて 403。→ Task 1。
4. **巨大ディレクトリ（`md ~` など）**: 除外ディレクトリには降りないので、`node_modules` の下は走査されない。→ Task 1。
5. **Mermaid の構文エラー**: そのブロックだけがエラー表示になり、本文の他の部分と他の図は描画される。→ Task 4。

### Task 2: HTTP ハンドラと SSE ウォッチャ

**Files:**
- Modify: `main.py`
- Test: `tests/test_http.py`

**Interfaces:**
- Consumes: Task 1 の全関数、`DIST_DIR`
- Produces（`main.py`）:
  - `class Watcher` … `__init__(self, root: Path, interval: float = 0.3)`, `start()`, `stop()`, `subscribe() -> queue.Queue[tuple[str, dict]]`, `unsubscribe(q)`。スレッドで `interval` ごとに `build_tree` と各 .md の `stat().st_mtime_ns` を取り、変化したパスは `("change", {"path": p})`、.md の集合が変わったら `("tree", tree_response)` をすべての購読キューに入れる。消えて再び現れたファイルは `change` として扱う（atomic save 対策）。
  - `make_handler(root: Path, initial: str | None, watcher: Watcher, dist: Path) -> type[BaseHTTPRequestHandler]` … URL 設計表のとおりにルーティングする。パスは `urllib.parse.unquote` してから `safe_path` に渡す。`log_message` は何も出さない。
  - `tree_response(root, initial) -> dict` … `TreeResponse`（`rootName` は `root.name`）
  - `main(argv: list[str] | None = None) -> None` … `dist/index.html` が無ければ stderr に「フロントエンドが未ビルドです。cd <DIST_DIR.parent> && npm install && npm run build を実行してください」を出して `SystemExit(1)`。起動したら標準出力 1 行目に `http://127.0.0.1:<port>/<initial を URL エンコードしたもの>`（initial が無ければ `/`）を出して flush。`--no-open` でなければ `webbrowser.open` を呼ぶ。Ctrl-C で静かに終了。

### Task 5: サイドバー（ツリー・目次）とページ内遷移

**Files:**
- Create: `frontend/src/components/App.tsx`, `frontend/src/components/Sidebar.tsx`, `frontend/src/components/FileTree.tsx`, `frontend/src/components/Toc.tsx`, `frontend/src/components/DirectoryListing.tsx`, `frontend/src/nav.ts`

**Interfaces:**
- Consumes: `api.ts` の全関数、`Content`、`StatusIndicator`、`TreeResponse`、`TocItem`
- Produces:
  - `nav.ts`: `pathFromLocation(pathname: string): string`（先頭 `/` を除いてデコード。`/` → `""`）、`resolveMarkdownLink(currentPath: string, href: string): string | null`（`href` が相対または `/` 始まりで、`#` やクエリを除いた部分が `.md`/`.markdown` ならルート相対パスを返す。`http:` 等の外部 URL、`#` のみ、`mailto:` は `null`）、`toUrl(path: string): string`（各セグメントを `encodeURIComponent` して `/` で連結）
  - `App`: 起動時に `fetchTree`。URL のパスが空なら `initial` があればそれに `history.replaceState`、無ければ `DirectoryListing`。ディレクトリを指すパスならそのディレクトリの `DirectoryListing`（ツリーから該当ディレクトリの .md 一覧）。本文内リンクのクリックを捕まえ、`resolveMarkdownLink` が値を返したら `history.pushState` してページ内で切り替える（修飾キー付きクリックは素通し）。リンクの `#hash` はスクロール先として扱う。`popstate` で追従する。`onChange(path)` が現在のパスと一致したら `reloadToken++`。`onTree` でツリーを更新する。
  - `Sidebar`: props `{ tree: TreeNode[]; current: string | null; toc: TocItem[]; onNavigate(path: string): void }`。上半分が `FileTree`、下半分が `Toc`（`flex: 1 1 50%`、各 `overflow: auto`）。トグルボタン（`aria-label="サイドバーを切り替え"`）で全体を隠す。状態は `localStorage["md.sidebar"]`（`"open"`/`"closed"`）に保存し、読み書きは try/catch で囲む。保存値が無いときは `matchMedia("(max-width: 800px)")` が真なら閉じた状態で始める。
  - `FileTree`: 現在のファイルを強調し、その祖先ディレクトリは展開する。ディレクトリはクリックで開閉できる。
  - `Toc`: クリックで `document.getElementById(id)?.scrollIntoView()`。
